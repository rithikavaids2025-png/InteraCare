# InteraCare – Drug Interaction Intelligence

A single-page web dashboard that screens drug combinations for interaction severity and
estimates the risk for pairs that have no recorded severity, using a gradient-boosting model
trained on the **DDInter** interaction network.

> For education and research. Not a substitute for clinical judgement.

## Run it

No install, no build step, no server needed.

```
double-click index.html          (or)
python -m http.server 8000       then open http://localhost:8000
```

Internet is only used to load the two Google Fonts (Fraunces, Public Sans). Offline, the app
still works and falls back to Georgia / system-ui.

## What's inside

| Screen | What it does |
|---|---|
| Dashboard | KPIs, severity donut, top drugs by major interactions, 12-drug heatmap, partner-count histogram, quick check |
| Interaction checker | Add 2+ drugs, every pair is screened, worst severity banner + advice, sorted pair table, heatmap |
| Drug explorer | One drug, all partners, filter by severity, text filter, pagination |
| Risk predictor | Two drugs: documented severity if recorded, otherwise model probabilities (Minor/Moderate/Major) + 0-100 risk index + the evidence used |
| Model & pipeline | 8-step workflow, 3-model comparison, feature importance, confusion matrix |

## Retrain the model

```
cd pipeline
pip install -r requirements.txt
python train_model.py                              # trains from ../data/ddinter_pairs.csv
python train_model.py --ddinter-dir <folder>       # or from the raw 8 DDInter CSV downloads
python train_model.py --out ../js/data/model-data.js   # replace the model the website uses
```

The raw files come from https://ddinter.scbdd.com/download/ (files `ddinter_downloads_code_A/B/D/H/L/P/R/V.csv`).

`train_model.py` is a reconstruction of the original offline training (the original notebook is not
part of the app). What was checked:

- The 13 features match the JavaScript `feats()` exactly (max difference 1e-15 on 300 pairs).
- Gradient boosting (the deployed model) retrains to 87.3% accuracy, recall 90/87/89% - the app shows 87.3%, 90/86/90%.
- Logistic regression retrains to ~80.0% (app: 79.6%).
- Random forest comes out higher (~93%) than the app's 89.9% because the original forest settings
  were not recoverable; the "Profile baseline" row on the Model screen also cannot be regenerated by this script.
- An exported retrained model was loaded into the website and scored 89.2% on graded pairs, same as the shipped one.

The shipped `js/data/model-data.js` is the original model - the script writes to `pipeline/output/` unless you pass `--out`.

## Data note

DDInter severity labels: Major, Moderate, Minor, Unknown. Only graded pairs (Minor/Moderate/Major,
130,422) are used for training/validation; Unknown pairs still count as edges in the network features.
Chemical structure and pharmacology are not in DDInter's severity files; adding them is the obvious next improvement.
